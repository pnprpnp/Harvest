# 特性テスト

このテストは、コード整理の前後で Harvestnavi の現在の動作が変わっていないことを確認するためのものです。実際の `index.html` と `apps-script/コード.js` をそれぞれ隔離したブラウザー環境で読み込み、画面側の動作と同期仕様をまとめて確認します。

テスト開始前に、両方の生成ファイルが機能別ソースと一致していることも自動確認します。

## 実行方法

```sh
python3 tests/run_characterization.py
```

Node.js が使える環境では、次のコマンドでも同じテストを実行できます。

```sh
npm test
```

Google Chrome または Chromium が必要です。標準の場所にない場合は `CHROME_BIN` に実行ファイルの場所を指定します。

テストは一時的なブラウザープロファイルで動くため、普段使っている Harvestnavi の記録や設定には触れません。手動で `tests/characterization.html` を開いた場合も、同じURLに保存されていたブラウザー内データをテスト終了後に戻します。

Apps Script側では `PropertiesService` と `SpreadsheetApp` をテスト専用の代用品（mock）へ差し替えます。実際のスプレッドシートやスクリプト プロパティは読み書きしません。

## 固定している動作

- パレット番号と保存用範囲の相互変換
- 画面に表示する収穫場所とパレット番号の相互変換
- 途中収穫場所の入力補正
- 収穫記録の読み込み・保存形式
- 現行・旧形式および競合退避用スナップショットの共通正規化
- 同じ日の通常収穫と途中収穫のケース数表示
- 過去記録の編集時に、それ以降の記録を計算から外す処理
- 重複記録と収穫済みパレット再使用の検出
- 同期時の内容比較、UUID／記録IDによる識別と競合記録の照合
- ブラウザー側とApps Script側の同期上限・同期項目・API操作名
- 収穫記録・苗植え記録・同期カーソルの送受信互換性
- Apps Script側の入力拒否とスクリプト プロパティによる接続先取得
- 記録変更後の派生キャッシュの一括解除
- 情報ウィンドウの開閉、重なりと背景スクロール
- メインタブの定義、即時切り替えと遅延ロード表示

仕様として動作を変更した場合だけ、変更内容を確認したうえで期待値を更新します。
